# T&T Remap Updates

คลังเผยแพร่ตัวติดตั้งและแพตช์โน้ตของ T&T Remap สำหรับ Windows

- [ดาวน์โหลดและอ่านแพตช์โน้ตเวอร์ชันล่าสุด](https://github.com/tawanokofficial-stack/tt-remap-updates/releases/latest)
- ตัวติดตั้งมี ia32 (32 บิต), x64 (64 บิต) และ ARM64
- โปรแกรมที่ติดตั้งแล้วตรวจอัปเดตจากช่อง stable และตรวจลายเซ็นพร้อม SHA-256 ก่อนติดตั้ง
- ตรวจทันทีในโปรแกรม: อัปเดต → ตรวจอัปเดต
- การเข้าใช้งานโปรแกรมต้องใช้คีย์ที่ได้รับจากผู้ดูแล

คลังนี้เก็บเฉพาะไฟล์แจกจ่ายสาธารณะและข้อมูลเวอร์ชัน ไม่มีคลังจูนส่วนตัวหรืองานลูกค้า
